# Advanced Slot Booker
An automatic slot booker written in python, with a GUI.  

## Preview
![Advanced Slot Booker Screenshot](screenshots/ASB.png)

## Install
### Linux
```
git clone https://github.com/nishanthgit3/AdvancedSlotBooker
cd AdvancedSlotBooker
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python3 main.py
```

## Run
### Linux
```
source .venv/bin/activate
python3 main.py
```
